Bob IDE Session Screenshots



This folder contains screenshots of Bob IDE task session summaries, as required by the hackathon submission rules.

For each Bob task session used in this project, export the task session consumption summary from Bob IDE and save it as a PNG file in this folder.

File naming convention



teamname\_taskNN\_short-description\_summary.png



Example: mldive\_task01\_repo-onboarding\_summary.png



How to export a session summary from Bob IDE



&#x20;   Open Bob IDE.



&#x20;   Go to the Tasks panel.



&#x20;   Select the task you want to export.



&#x20;   Open the task session consumption summary.



&#x20;   Take a screenshot and save it as PNG.



&#x20;   Rename it using the convention above.



&#x20;   Place it in this folder.
