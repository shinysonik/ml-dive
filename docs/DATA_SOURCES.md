\# Data Sources



This document lists all data and assets used in ML-Dive, as required by the hackathon rules. The rules ask participants to keep a list of every source they use, to confirm that no personal information, client data, company confidential data, or social media data is involved.



\## Summary



All data in this project is either \*\*synthetic\*\* (generated by us) or \*\*public\*\* (used under a license that permits commercial use). We do not use personal information, client data, company confidential data, or data from social media.

| | |

|---|---|

| \*\*Description\*\* | Synthetic training run with 100 epochs × 50 iterations = 5000 rows.
